## Review 方式

文档中的内容分为三类：

- **当前共识**：目前已经基本确认，后续设计以此为基础。
- **暂定方案**：当前建议这样处理，但还可以根据实际情况调整。
- **待讨论**：缺少业务细节，或者存在多个可选方案，需要继续确认。

Review 时可以直接指出：

- 哪一段描述不符合实际；
- 哪个名称不容易理解；
- 缺少了什么正常流程或异常情况；
- 哪个暂定方案需要改变；
- 哪个问题应该优先讨论。

讨论产生结论后，会直接更新对应文档，不要求按照文档顺序提供信息。
